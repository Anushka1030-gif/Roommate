  - Inbox overview endpoint (`GET /api/conversations`) returning conversation partners, last message snippet, timestamp, unread count, and strict privacy protection (no email/phone exposure).
  - Paginated chat message history (`GET /api/conversations/:id/messages`) with cursor pagination (`before`, `limit`), participant authorization (`403 FORBIDDEN`), bidirectional block protection, and automatic read-receipt updates for incoming messages.
  - REST message dispatch endpoint (`POST /api/conversations/:id/messages`) with rate limiting (`messageSendLimiter`), Zod body validation (1-1000 chars), atomic transactional storage with conversation timestamp update, and rate-limited email notification dispatch to recipients.
  - Explicit read receipt endpoint (`POST /api/conversations/:id/read`).
  - Socket.IO real-time server (`server/src/sockets/chat.socket.js`) with JWT cookie/handshake authentication middleware, personal user rooms (`user_${userId}`) for live inbox updates, conversation rooms (`conversation_${convId}`), real-time message broadcasting (`new_message`, `inbox_update`), read receipts (`mark_read`, `messages_read`), and typing status indicators (`typing`, `user_typing`).
  - Zod validation schemas (`server/src/validations/conversation.validation.js`) with standardized error envelope and custom error codes.
